# 🎓 Система аттестации

Веб-приложение для проведения аттестации сотрудников: тестирование,
управление вопросами, статистика, отчёты.

Стек: **Streamlit + MySQL + Nginx + systemd**.

## 🚀 Возможности

- 🔐 Аутентификация (роли: admin / manager / user)
- 📝 Тестирование по темам
- 📊 Результаты и статистика
- ⚙️ Админ-панель: вопросы, пользователи, отчёты
- 📥 Импорт / экспорт вопросов (CSV, JSON)

## 🛠️ Установка

См. [docs/INSTALL.md](docs/INSTALL.md).

## 📂 Структура
├── app.py # главная страница (логин)
├── config.py # конфигурация
├── database.py # слой работы с БД
├── pages/ # страницы Streamlit
├── utils/ # утилиты (auth, io)
├── migrations/ # SQL-миграции
├── requirements.txt
├── .env.example # шаблон переменных окружения
└── README.md


## 🔒 Безопасность

- Не коммитьте `.env` — используйте `.env.example` как шаблон.
- Пароли хешируются (`sha256 + salt`).
- Смените `admin/admin123` в продакшене.
